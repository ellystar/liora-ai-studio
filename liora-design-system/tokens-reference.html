01 · The principle

Primitives are the brand.
Roles are the interface.

Two layers, and the split is the whole point. Primitives hold the brand constants — bone, ink, gold, oxblood. Semantic roles describe a job — surface, border, content, danger. Components may only ever touch the second layer.

Do

color: var(--content-primary)

Names a job. Survives a theme switch, a palette revision, and the day the app grows a dark mode. This is the only layer a component should know about.

Don't

color: var(--ink)

Names a colour. Reads perfectly in light and disappears in dark. Every primitive referenced inside a component is a future bug with a delay fuse.

02 · Colour · primitives

Warm, never grey.

The neutrals carry a paper warmth; there is no cool grey anywhere in the system. There are exactly two accents, and they hold different jobs — using one where the other belongs is the fastest way to make the brand look borrowed.

05 · Motion & form

One curve. Two tempos.

The whole brand eases on cubic-bezier(.22, 1, .36, 1) — a fast start that settles rather than bounces. What changes between the site and the app is duration, not character.

TokenValueWhere
--liora-dur-fast150msHover, press, focus. State feedback should feel instant.
--liora-dur-base300msThe app default. Menus, tabs, toggles, drawers.
--liora-dur-slow500msDisclosure, panel open, height changes.
--liora-dur-reveal800msMarketing scroll reveals only. In a tool this reads as lag, not elegance.
--liora-radius2pxThe house radius. Liora is not a rounded brand — pills are for avatars and counters, nothing else.

06 · Site → Atelier

What a product needs that an essay doesn't.

The site never had to tell anyone a payment failed. These are the five decisions taken while extending the language, and the reasoning behind each — so the next person extends it the same way.

Feedback colours
Danger reuses oxblood, warning reuses gold. Only success needed a new hue, and it is a muted olive rather than a supermarket green. A restrained palette is part of the brand, not a limitation to route around.
Separation
Hairlines before shadows. The site separates everything with a 1px stone rule and no elevation at all. The app keeps that instinct; shadow is reserved for things that truly float above the page.
Tempo
300ms, not 800ms. The site's slow reveals are a reading experience. In a tool the same timing reads as latency — same curve, shorter duration.
Density
New UI sizes, no new families. 15 / 13 / 12px were added for dense interface text. The display scale was left untouched — an app still gets full-size headings where it is saying something.
The italic
Ration it harder in product. One soul word per view on the site; in the Atelier, reserve it for empty states and moments of arrival. It cannot survive appearing next to a data table.

07 · Install

Three files.

liora-tokens.cssPrimitives, semantic roles, light and dark, plus the type classes. Framework-agnostic — drops into the existing design-system HTML as-is.
liora.preset.tsTailwind preset. Exposes both the raw brand colours and the semantic roles, so bg-surface-raised and text-content-secondary are theme-aware out of the box.
liora-tokens.jsonW3C-format tokens for Figma, Style Dictionary, or any pipeline that wants the values as data.
// app/layout.tsx
import "./liora-tokens.css";

// tailwind.config.ts
import liora from "./liora.preset";
export default {
  presets: [liora],
  content: ["./app/**/*.{ts,tsx}", "./components/**/*.{ts,tsx}"],
};

// then, in a component
<button className="h-control-md rounded bg-surface-raised
  text-content border border-line transition-colors
  duration-fast ease-liora hover:border-line-strong">
